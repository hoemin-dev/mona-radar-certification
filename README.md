# MONA RADAR Certification

SMPP 기술개발제품 공개 검색 화면을 기반으로 인증 이력을 수집하기 위한 조사/설계 저장소입니다.

현재 단계는 **Collector 구현 전 구조 조사**입니다. 전체 크롤러나 대량 수집은 포함하지 않습니다.

## 조사 기준

- 기준 URL: <https://www.smpp.go.kr/prd/prdinfo/tdprd/SelectTdPrdListVw.do>
- 조사일: 2026-08-14 (KST)
- 공개 상태, 비로그인 접근
- 과거 이력 수집의 기본 조건: `인증기간 만료업체 포함 = Y`

## 문서

- `docs/source-smpp.md`: 검색 UI, POST 파라미터, 만료 포함 상태, 페이지네이션, 상세 진입 조사
- `docs/fields.md`: 필드별 수집 위치와 정규화 요구사항
- `collector/README.md`: 다음 단계 Playwright Collector의 최소 설계
- `db/schema-draft.sql`: 조사 결과 기반의 보수적인 스키마 초안

## 현재 결론

목록만으로 인증구분, 인증제품/기술명, 인증번호, 업체명, 대표자, 주소(값이 제공되는 경우), 인증일자, 만료일자를 수집할 수 있습니다. 사업자등록번호와 세부품명번호는 검색 입력은 존재하지만 목록 출력에는 없었습니다. 화면에는 상세 이동 함수가 정의되어 있으나 조사한 공개 결과 행에는 상세 링크/클릭 핸들러나 내부 식별값이 렌더링되지 않아 상세 필드는 현재 `확인 불가`입니다.
